# 重生 之 我和机娘杀疯了

[在线试玩](https://freefoxcm.github.io/FAG/) · [五机机库](https://freefoxcm.github.io/FAG/?hangar&model=akari)

电脑浏览器单人街机空战首版。五位机械生命可从标题页或机库选机，以独立战机形态与技能突破临港封锁。全中文界面，包含可跳过剧情、城市、峡谷和远海三关战役、三个两阶段 Boss、局内火力升级、技能演出和结算。

## 运行

需要 Node.js 22.12+（本机已使用 Node 24 验证）。

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5180 。如果端口已被占用，以终端实际输出为准。

```powershell
npm run build        # 类型检查并构建至 dist/
npm run preview      # 预览生产构建
npm run assets       # 用 Blender 重建机体、场景模块、道具、LOD 和贴图
npm run assets:campaign # 重建敌机、Boss、场景与道具（复用已有源贴图）
npm run test:campaign # 三关、道具、部件、大招与 1080p 性能验收
npm run test:balance  # 五位机娘 × 三关的固定脚本输出对照
node scripts/validate-campaign-assets.mjs # UV、炮口、喷口及 Boss 部件验证
npm run assets:roster # 仅重建其余四位机娘的模型
npm test             # 规则与整关模拟测试
npm run test:browser # 开发服务器运行时执行浏览器场景测试
node scripts/benchmark.mjs # 使用默认图形后端采样 1080p 表现
npm run test:upgrade # 六种模型、PBR、锚点、音效与三类战斗压力验收
npm run test:record  # 无无敌或血量修改的键盘实战录像
npm run test:hangar  # 五架机体、机库交互、LOD 和资源回收
npm run test:pilots  # 五机选机、技能、胜负、重开与角色存档
```

浏览器测试默认使用本机 Chrome；可以通过 `PLAYWRIGHT_CHANNEL` 改为 `msedge`，通过 `GAME_URL` 指定开发服务器，`SOFTWARE_RENDERER=1` 可强制软件渲染。测试截图与 JSON 报告输出到 `artifacts/`。生产构建不包含调试接口。资源全部随项目提供，没有运行时 CDN、账号、联网存档或外部字体依赖；离线游玩时仍需本地静态服务器。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键，主炮自动射击 |
| 角色小技能 | E，技能与冷却随角色变化；详情见下表或暂停菜单 |
| 角色大招 | Q，击杀充能至 100 后释放；详情见下表或暂停菜单 |
| 暂停 / 继续 | Esc；失焦或切换后台自动暂停 |
| 推进剧情 | Enter / 空格，也可点击继续或跳过 |

带 ↑ 标记的金色双炮管武器舱将火力提升至三级；带 + 标记的青绿色维修舱修复一格耐久。靠近时显示名称，拾取时显示实际收益或已满提示。普通攻击扣一格，重型弹扣两格，受击后有 1.25 秒保护。3.5 秒内连续击杀延续连击，每十连击提升一档倍率，最高五倍。重开清空局内强化；全局最高分、各机体最高分、所选角色、声音、画质和镜头震动设置保存在浏览器本地；旧版存档自动兼容。HUD 显示当前关卡最佳，结算显示当前机体在该关的最佳成绩；全局和机体历史最高分继续保留。

## 内容与实现

- `src/game/`：纯规则模拟、角色/武器/关卡定义、输入和存档。固定 60Hz 更新，战斗使用平面碰撞。
- `src/render/`：Three.js 镜头、实例化城市/港区、模型加载、实体和粒子复用。航空高度用于立体表现，建筑不是可碰撞障碍。
- `src/ui.ts`、`src/style.css`：DOM 菜单、剧情、HUD、技能演出、设置与结算。
- `assets/source/`：十种机体的可编辑 `.blend`、颜色/法线/ORM 贴图及优化报告；`scripts/author-models.py` 与 `scripts/author-roster.py` 是可重复建模源，详细重建方法见 `assets/README.md`。
- `public/assets/`：运行资源。角色海报由用户提供的青鸾概念图转为 WebP；概念图及设计基准原样保留在 `reference_resources/`。

三关依次为「重返临港」「峡谷断链」「远海破晓」，首次通关解锁下一关，已通关关卡可重玩。Boss 分别于 200、215、230 秒入场，半血进入第二阶段。每关约 4–6 分钟，每次出击重新建立局内强化。临港通过滚动地块衔接城市与港区。音乐与音效用 Web Audio 合成，由首次用户点击解锁，无配音。

敌机从摄像机视野上方外侧连续进入，地面炮台从道路边驶入。炮弹使用真实炮口坐标和高度，Boss 预警攻击连接当前炮口与标记位置。E 导弹具备发射脉冲、锁定环、追踪拖尾与命中光环；Q 大招具备扩散冲击环、打击光柱和左侧及上下透明渐隐的机娘特写，技能文字独立于遮罩。拖尾使用实例化批次，特效对象可复用。

原始设计中五位角色均为原创虚构机械生命，地域信息仅作为美术参考。当前五架均可出战全部三关；未制作人形 3D、实时变形、联网模式或局外养成。

## 验证与性能边界

`npm test` 覆盖移动边界、暂停、碰撞与无敌、扫掠碰撞、机翼代理、航线与数量上限、闪避延迟和冷却、攻击前摇、转向炮口、顿帧输入、导弹、拾取、大招、Boss 阶段、胜负重置和存档容错；整关测试使用脚本瞄准和受击保护验证流程可完成，不能替代真人难度评价。

`test:browser` 使用 1366×768 和 1920×1080，验证剧情、键盘移动、暂停/恢复、设置持久化、大招特写、Boss、胜负、三次重开和失焦暂停。通关和失败场景由开发调试接口设置，真实规则由独立模拟测试覆盖。

目标为桌面硬件加速浏览器 1080p / 60 FPS。高画质启用阴影及更多粒子，流畅画质关闭阴影并限制像素比。SwiftShader 是软件渲染，测试帧率不能作为真实显卡表现；新版本以 `artifacts/campaign/playtest.json` 的图形后端与实测帧时间为准。机体使用 Blender GLB、PBR 贴图和预过滤环境反射；建筑和树木使用 Blender 模块实例化，地形、港区与舰船使用共享几何体批次；环境细节密度仍低于参考视频。

## 战斗升级

四类敌机分别为编队、截击、重装和支援。采用入场、攻击、机动/闪避、离场状态；截击机有约 0.25 秒反应、2.5 秒闪避冷却和三单位侧移上限，只预测主炮弹道。E 导弹继续追踪，Q 范围攻击不触发闪避。危险攻击有至少 0.6 秒前摇，瞄准位置在前摇开始时确定。

主炮使用实体弹芯和能量曳光，导弹具有壳体、鼻锥、尾翼和尾焰；弹体以实例化批次渲染。普通命中在实际碰撞点生成爆闪、火花、烟雾和撞击音，模型短暂闪亮和回弹；导弹、击毁与 Boss 连爆增加碎片、低频音效和镜头冲击。按事件等级触发限频顿帧，期间技能输入继续排队，恢复时不补跑积压帧。镜头震动可在设置中关闭。

模型近景预览：`http://127.0.0.1:5180/?preview&model=qingluan`。该工具只在开发构建提供，不占用战斗 HUD。

## 五机机库

标题页点击「战机机库」，或打开 `http://127.0.0.1:5180/?hangar&model=akari`。青鸾、明璃、苍穹、星隼、霜翼均有独立 3D 模型；可拖动旋转、滚轮缩放，按 1—5 切换机体。机库提供近景、俯视、侧视、后视，展示/战场光照、近景/战斗 LOD 和概念三视图对照。机库随生产构建提供，模型按需加载并释放旧资源。

机库点击「确认出战」进入对应角色的开场剧情；标题页也可直接切换五架。所选模型、炮口、尾焰、主题色、HUD、角色海报、大招特写、无线电与结算台词一起切换。重开保留角色并清空所有局内强化和临时技能。资产规格、源文件和重建方法见 `assets/README.md`。


## 五机作战

| 角色 | 主炮与机动 | E 小技能 | Q 大招 |
| --- | --- | --- | --- |
| 青鸾 | 均衡速度，散射制空 | 青羽齐射：6 枚分配目标的导弹，9 秒冷却 | 天穹裁决：清屏弹幕，对可见敌人造成 55 伤害 |
| 明璃 | 速度更快，较集中弹道 | 朱羽点杀：6 枚高速导弹集中锁定准星附近目标，8 秒冷却 | 绯空一线：沿前方锁定目标的航线贯穿，105 伤害，仅清除该航线敌弹 |
| 苍穹 | 中等速度，电子压制 | 镜像诱饵：侧前方诱饵存在 4 秒，吸引新一轮瞄准、拦截敌弹，10 秒冷却 | 苍穹静默：清弹、30 伤害，7 秒内减慢敌机和攻击节奏，使其承受 1.5 倍伤害 |
| 星隼 | 较快速度，协同输出 | 双隼编队：双无人僚机自动支援 7 秒，11 秒冷却 | 星链协同：清弹、20 伤害，标记敌人 6 秒使其承受 1.3 倍伤害，并发射 12 枚协同导弹 |
| 霜翼 | 速度较慢；低射速重炮贯穿 3 个目标 | 矢量突进：沿当前移动方向冲刺，未移动时前冲，短暂免伤，7 秒冷却 | 极寒破阵：清弹，连续发射 5 发重型贯穿弹，每发 18 伤害 |

所有角色保留五格耐久、三级火力、连击计分与现有两阶段 Boss。导弹技能需要前方目标，诱饵、僚机和冲刺可以提前释放。诱饵不改变已经预警锁定的落点；干扰和标记随模拟时间衰减，暂停时不计时。主炮与贯穿弹使用扫掠碰撞，同一弹体不会重复伤害同一目标。

角色定义集中在 `src/game/characters.ts`，规则保留在独立模拟中，持续诱饵/僚机/标记表现位于 `src/render/pilot-fx.ts`。本轮为五机首轮可玩平衡，后续可依据试玩继续调校。

`npm test` 包括每架的完整关卡模拟；`npm run test:pilots` 输出 `artifacts/pilots/report.json` 与分角色截图。生产构建可用 `node scripts/smoke-pilots-production.mjs` 检查。明璃无辅助实战录像位于 `artifacts/pilots/natural-akari/`。通关与结算自动化使用开发场景设置或受击保护，实战录像只操作键盘，不修改战斗状态。

## GitHub Pages 发布

仓库：`freefoxcm/FAG`，线上地址：`https://freefoxcm.github.io/FAG/`。推送 `main` 后，`.github/workflows/pages.yml` 自动安装依赖、执行规则测试、构建并部署 `dist/`，也可从 Actions 手动运行。Pages 的发布源设为 GitHub Actions。

`VITE_BASE_PATH` 控制网站子路径；工作流使用 `/FAG/`。模型、角色海报、概念图、CSS 和站内导航共用这一前缀。默认本地开发仍使用 `/`。可按线上路径在本地复核：

```powershell
$env:VITE_BASE_PATH = '/FAG/'
npm run build
npm run preview -- --port 5181 --strictPort
# 另开终端：
node scripts/smoke-pages.mjs
# 针对已上线地址验收：
$env:PAGES_URL = 'https://freefoxcm.github.io/FAG/'
$env:PAGES_OUTPUT = 'artifacts/pages-live'
node scripts/smoke-pages.mjs
```

Git 仓库包含游戏代码、建模脚本、测试与优化后的运行素材。原始参考视频/概念图、Blender 制作源和纹理工作文件保留在本地的 `reference_resources/`、`assets/source/`，不上传；普通运行与构建无需这些制作原件。重建美术时需要补齐本地制作资料。测试截图、录像、Blender 便携版和依赖目录同样不上传。

## 三关战役与部件拆解

Boss 的炮组、引擎、雷达或护盾发生器各有耐久。走位使用主炮击中不同部件；追踪技能优先锁定前方部件，目标损坏后自动重新锁定。炮组破坏后停止对应炮位攻击；长夜引擎损坏降低移动范围，棱镜雷达损坏取消额外追踪预警，天幕护盾发生器全部损坏后解除核心减伤。部件得分只结算一次，核心归零完成关卡。无需新增按键。

支援机和地面雷达会标记当前玩家位置，指挥附近最多两架友机在预警后齐射。及时击毁指挥源可打断尚未发射的协同火力。雷达、防空炮和导弹阵地可以摧毁；房屋、植被和峡谷不参与飞行碰撞。

本轮平衡调整：明璃点杀导弹每枚 8 伤害；苍穹主炮每发 1.2 伤害、0.13 秒间隔；霜翼主炮每发 2.0 伤害。完整输出对照见 `artifacts/campaign/balance.json`，该报告使用受击保护，不能代替实际难度判断。无血量或无敌修改的键盘实战录像由 `npm run test:record` 单独生成。
